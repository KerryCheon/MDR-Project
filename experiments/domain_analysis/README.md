# Domain Analysis (MDR)

Goal: understand soil moisture dynamics and rainfall response before making new modeling decisions

## Primary questions

1. How persistent is soil moisture over time (per station)?
2. What does the impulse response of soil moisture to rainfall look like?
3. Are there regimes (dry vs wet, seasonal, station-specific) that change the response?
4. When do satellite signals (SAR/optical/LST) add signal beyond rain + memory?
