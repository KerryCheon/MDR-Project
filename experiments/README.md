# experiments/

Exploratory analyses and diagnostic experiments conducted during model development.

- `domain_analysis/` — soil moisture and rainfall domain characterization (seasonal patterns, distributions)
- `analysis/` — general data exploration and heatmap visualizations
- `correlation/` — feature-target and inter-feature correlation analysis
- `interpolation/` — evaluation of interpolation strategies for gap-filling
- `missing_values/` — missing value characterization and imputation diagnostics (ground truth and satellite)

Each subdirectory contains one or more notebooks and a companion PDF report.
