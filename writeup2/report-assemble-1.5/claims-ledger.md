## Reporting constraints

The 2023–2025 test period informed feature, hyperparameter, and later design choices. The seven-station LOSO analysis is small, and predictor-seed intervals exclude feature/model-selection uncertainty. ECE mapping was selected using Washington validation; the five-station late-summer evaluation is separate from model fitting. The precipitation-index labels and model-specific predictor indices use separate numbering conventions. The paired-global temporal refit reproduces the earlier sensitivity-anchored values exactly; for LOSO, this report uses 0.579737, the mean of the saved seed rows in both harnesses, rather than the stale 0.5795 value in an older summary file.
