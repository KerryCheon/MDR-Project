## Reporting constraints

The seven-station LOSO analysis is small, and predictor-seed intervals exclude feature/model-selection uncertainty. P-values are not reported: the comparisons rest on few independent units (seven held-out stations, one 2023–2025 test period), and the 30 temporal runs vary only in the predictor seed, so a significance test on them would overstate the evidence. ECE mapping was selected using Washington validation; the five-station late-summer evaluation is separate from model fitting. The precipitation-index labels and model-specific predictor indices use separate numbering conventions. The paired-global temporal refit reproduces the earlier sensitivity-anchored values exactly; for LOSO, this report uses 0.579737, the mean of the saved seed rows in both harnesses, rather than the stale 0.5795 value in an older summary file.
