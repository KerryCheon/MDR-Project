# docs/
Here's an incomplete knowledge base for the MDR project. This is a work in progress and will be updated over time.

It's intended for cross-components documentation (i.e. across multiple notebooks); for component-specific documentation, please see the `docs/` folder in each component's subdirectory (e.g., `src/pipeline/docs/`). 

## Rules
- Ensure the contents are up-to-date with the latest code and notebooks. If you created a new notebook or made a change to the pipeline, please update the docs accordingly.
- DO NOT edit `docs/changelogs/`, they are meant for human collaborator to storing notes.
