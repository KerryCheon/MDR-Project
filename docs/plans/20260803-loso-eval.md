# Plan: `derived_8.4-eval-1.2` — Leave-One-Station-Out (LOSO) Spatial Generalization

## Objective
Create a new experiment `notebooks/experiment/derived_8.4-eval-1.2/` based on `derived_8.4-eval-1.1` (retaining **all existing features**: 54-feature shared backbone, V0-50 baseline features, candidate pool, same 6 routing strategies, same XGBoost hyperparameters, same delta-grid configs) that runs **leave-one-station-out** evaluation for **all 47 configurations** from eval-1.1, and collects **per-configuration × per-station metrics** so difficult stations can be identified as a byproduct.

**Confirmed with user:** (1) evaluate all 47 configurations (2 baselines + 5 MoE strategies × 9 delta-grid points); (2) **persist model weights** — save every fold's trained booster weights (`.json`, same format as eval-1.1) under `models/`, in addition to predictions and metrics. Storage will be comparable to or larger than eval-1.1's 2.9GB (644+ expert boosters ≈ 5–9GB; noted in README).

## Background (from exploration)
- `derived_8.4` split: 7 WA stations; trainval = train(2017–2020)+val(2021–2022); test = 2023–2025 (6,620 rows).
- eval-1.1's `run_eval.py` + `eval11/` package: strategies `Global_Single`, `Clustering_V0_Full_k2`, `Clustering_Dynamic_k2`, `Univariate_G_API_k2`, `Seasonal_Binary_k2`, `Trained_Gating_k2`; each MoE strategy searched a (c0, c1 ∈ {0,5,10}²) delta grid; exact per-config cluster additions are recorded in `delta_grid_summary.csv` (semicolon-joined, NaN = empty).
- eval-1.1 winners: `Clustering_V0_Full_k2` (0,10); all other strategies won at (0,0).
- Environment: H100 GPU free; xgboost 3.2.0 (CUDA works), sklearn 1.8.0, pandas 3.0.3 via `uv` in `notebooks/`.
- LOSO precedent (writeup `evaluation_spatial.tex`, v20.9 notebook): train on combined train+val of the 4 remaining stations, evaluate on all rows of the held-out station.

## LOSO Protocol (per configuration)
For each configuration (config_id, strategy, global_features, cluster_additions) and each held-out station s ∈ {BeaverPass_WA_990, CayusePass_WA, Darrington, Paradise_WA, Quinault, SourdoughGulch_WA_985, Spokane}:
1. `fold_trainval` = trainval excluding station s (rows from train+val); `fold_test` = all test rows of station s.
2. **Router refit per fold** on `fold_trainval` only (no held-out-station leakage into routing) — fresh router instance each fold.
3. Train experts per regime cluster (1 expert for `Global_Single`, 2 for MoE) on `fold_trainval[labels==cluster]` with the configuration's features (global + per-cluster additions), same XGBoost params as eval-1.1 (`device: cuda`, seed 42).
4. Predict on `fold_test`; compute pooled / per-year / per-regime metrics (r2, rmse, ubrmse, bias, mae, pearson).

**Note:** delta additions are **fixed from eval-1.1** (they were selected using the full test set), so LOSO measures generalization of model *training/fitting* given fixed features — documented as a caveat in README.

## Addendum (2026-08-04): Full-training baseline + station similarity analysis

Two follow-ups were added to `derived_8.4-eval-1.2` (in place):

### 1. Station similarity & clustering (spatial-generalization hypothesis)
- New `eval12/station_sim.py`: per-station feature vectors (29 static: geo + WorldClim BioClim
  BIO1-19 + soil; 10 observed climatology from train+val), z-score, Ward clustering + PCA,
  isolation scores (1-NN / mean / centroid distance), Spearman hypothesis test, 5 plot functions.
- New notebook section + 5 figures + README/config sections.
- **Finding:** 1-NN isolation correlates *positively* with aggregate LOSO difficulty (ρ = +0.73,
  p = 0.06) — the closest twin pair (CayusePass ↔ Paradise) are the hardest on average, so the
  simple "twin → easy" hypothesis is not supported; under the winner config the pattern flips
  (mean-distance ρ = −0.64), and the only grassland station (SourdoughGulch) is hardest both ways.

### 2. Full-training baseline (replicates derived_8.4-eval-1.1; LOSO is an addition, not a replacement)
- `eval12/evaluator.py` gained `evaluate_full()` (train router + experts on ALL 7 stations,
  evaluate per station on test); new `run_full_baseline.py` runs the same 47 pinned configs.
- Validated: per-config pooled test R² matches eval-1.1 (`delta_grid_summary.csv` /
  `metrics_summary.csv`) within 1e-6.
- Outputs: `full_per_config_station.csv`, `full_config_summary.csv`, `full_station_summary.csv`,
  `predictions_full/`; notebook section + 3 comparison figures (full-vs-LOSO scatter, paired
  bars, per-config LOSO-cost boxplot) + README/config sections.
- **Question answered:** are LOSO-hard stations also hard under full training? Spearman(full
  median, LOSO median) is weak-positive/insignificant at n=7; CayusePass is *generalization-
  limited* (full 0.78 vs LOSO 0.35, gap +0.43) while SourdoughGulch is *intrinsically hard*
  (0.47 vs 0.43, gap +0.04); BeaverPass shows an anomalous negative gap (better under LOSO).
