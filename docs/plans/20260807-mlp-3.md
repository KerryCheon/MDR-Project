## Part 1 — Analysis of `derived_8.4-eval-mlp-1.2`

### Results recap
- Honest (2-seed, val-selected) winners: 2regime_96 `w512x512x512_d0.3_lr1e-3` test R² 0.761; 2regime_54 `w512x512x512_d0.3_huber0.1` 0.765.
- Test-best references: 2regime_54 `w384x384_d0.3_gelu` 0.789 (val-rank 8 → honestly selectable); 2regime_96 `w512x512x512_d0.4` 0.784 / `w256x256_d0.5` 0.783 (1-seed).
- Offline ensembles: 2regime_54 val top-10 avg 0.786; 2regime_96 val top-5 avg 0.771.
- XGBoost references (eval-1.1): 2-regime winner 0.815 (test-selected), global 0.779.
- Budget used: 1.70 of 2.0 H100-hours (6,132 GPU-seconds, ~80 jobs, 8 parallel workers).

### Where the gap lives (quantified)
1. Selection gap ≈ 0.024 (val-selected 0.765 vs test-best 0.789). Spearman(val_rmse, test_r2) = +0.29 (54) but −0.22 (96).
2. Model ceiling ≈ 0.026 (0.789 vs 0.815).
3. Systematic positive test bias: 2regime_96 median +0.021 vs XGBoost +0.0065; bias² ≈ 10–17% of MSE.
4. Test error bottoms out early (~ep 90, rmse 0.0451) then rises while val stays flat → patience-60 cannot catch it.
5. Documented negatives to not repeat: aux2020 selection, trainval retrain, residual nets, FT-Transformer.

## Part 2 — 1.3 design and offline findings (before the sweep)

### Track A — offline analyses on 1.2 artifacts (zero GPU)
1. **`analyze_stopping.py`** (replays early-stopping rules on saved per-epoch curves):
   - patience-60 = best honest rule (mean pooled test rmse 0.0520 for 96, 0.0493 for 54).
   - val_aux helps 54 (0.0492) but hurts 96 (0.0538); plateau rules STOP TOO EARLY and are much worse (0.0556–0.0714).
   - Oracle (argmin test) bound: 0.0476 (96) / 0.0483 (54) — real but not honestly reachable.
   - **Decision: keep patience-60 (no trainer change).**
2. **`analyze_calibration.py`** (per-cluster affine fit on val → apply to test, per seed):
   - **The calibration does NOT transfer: calibrated test R² is worse for nearly every config** (e.g., 96 `w512x512x512_d0.4` 0.784→0.759; 54 `w384x384_d0.3_gelu` 0.789→0.751) and the test bias gets larger. The val→test bias relationship is period-specific (consistent with 1.2's "val is a weak proxy for test").
   - **Decision: raw predictions stand; calibration is a documented negative, not a champion step.** `run_mlp_eval.py` only reports calibrated rows if they beat raw (in practice none do).
3. Net effect: the remaining levers are train-time regularization (EMA, mixup, wd, bs256, target-centering), 2-seed completion of 1.2's strong 1-seed configs, and offline ensembles.
