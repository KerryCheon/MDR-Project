# Implementation Plan - derived_8.2-eval-3.0 (MoE Architectures Evaluation)

This plan outlines the creation and execution of the evaluation suite `derived_8.2-eval-3.0` focusing on Mixture of Experts (MoE) architectures on the Washington-only `derived_8.2` soil moisture dataset. 

We will train and evaluate 11 models in total using the step-shrinked XGBoost hyperparameter configuration from `derived_8.2-hyperparameters-1.3-lite`.

## Proposed Models (11 in Total)

1. **Model 1 (Baseline)**: Unweighted single global model using `OVERALL_SELECTED_FEATURES_V3` (47 features).
2. **Model 2 (Trained Gating K=2)**: Learned gating model (XGBoost Classifier) predicting dry/wet regimes (`y < 0.16` vs. `y >= 0.16`). Specialist models are trained on their respective subsets using `BINARY_REGIME_DRY_SELECTED_FEATURES_V1` and `BINARY_REGIME_WET_SELECTED_FEATURES_V1`.
3. **Model 3 (Trained Gating K=3)**: Learned gating model (XGBoost Classifier) predicting ternary regimes (`y < 0.16`, `0.16 <= y < 0.25`, and `y >= 0.25`). Specialist models are trained on their respective subsets using `TERNARY_REGIME_DRY_SELECTED_FEATURES_V1`, `TERNARY_REGIME_TRANSITION_SELECTED_FEATURES_V1`, and `TERNARY_REGIME_WET_SELECTED_FEATURES_V1`.
4. **Model 4 (Trained Gating K=2, V3 Features)**: Learned gating model (XGBoost Classifier) predicting dry/wet regimes (`y < 0.16` vs. `y >= 0.16`). Both specialists are trained on their respective subsets using `OVERALL_SELECTED_FEATURES_V3`.
5. **Model 5 (Trained Gating K=3, V3 Features)**: Learned gating model (XGBoost Classifier) predicting ternary regimes (`y < 0.16`, `0.16 <= y < 0.25`, and `y >= 0.25`). All three specialists are trained on their respective subsets using `OVERALL_SELECTED_FEATURES_V3`.
6. **Model 6 (Clustering K=2, Top 1)**: Deterministic gating based on `Univariate_G_API`. Specialists are trained using feature sets selected for each cluster.
7. **Model 7 (Clustering K=2, Top 2)**: Deterministic gating based on `Clustering_Dynamic`. Specialists are trained using feature sets selected for each cluster.
8. **Model 8 (Clustering K=2, Top 3)**: Deterministic gating based on `Seasonal_Binary`. Specialists are trained using feature sets selected for each cluster.
9. **Model 9 (Clustering K=3, Top 1)**: Deterministic gating based on `Clustering_V3_Full`. Specialists are trained using feature sets selected for each cluster.
10. **Model 10 (Clustering K=3, Top 2)**: Deterministic gating based on `Clustering_Dynamic`. Specialists are trained using feature sets selected for each cluster.
11. **Model 11 (Clustering K=3, Top 3)**: Deterministic gating based on `Univariate_G_API`. Specialists are trained using feature sets selected for each cluster.

## Proposed Changes

We will create a new experiment folder `notebooks/experiment/derived_8.2-eval-3.0/` containing:
1. **`run_cluster_feature_selection.py`**: A helper script to partition the dataset for each of the 6 clustering strategies and run the programmatic feature selection pipeline (`select_features` from `Modeling.Src.soilmoist_fl`) for each cluster. The output will be saved to `cluster_features.json`.
2. **`derived_8.2-eval-3.0.ipynb`**: The main evaluation notebook that reads `cluster_features.json`, trains all 11 models on `trainval`, predicts and evaluates on `test`, generates diagnostic plots, saves model weights to `models/`, and generates a performance summary table.
3. **`README.md`**: Summarizes the experimental setup, overall and year-by-year results, and key findings.

### 1. Feature Selection on Clusters (Feature Analysis Pipeline)

We will partition the training (`train`), validation (`val`), and test (`test`) splits according to the 6 clustering gating strategies.
- For `Univariate_G_API`, we compute quantile thresholds on the `train` set and apply them to all splits.
- For `Seasonal_Binary`, the grouping is month-based: dry (5-10) vs wet (11-4).
- For `Clustering_Dynamic` and `Clustering_V3_Full`, we fit a `StandardScaler` and `KMeans` model on the `train` set, then predict cluster labels on all splits.

For each of the 15 resulting clusters, we will run `select_features` with:
- Config: V3 settings (`top_k = 50`, `stability_n_boot = 100`, `min_freq = 0.6`, `mi k = 300`, `elasticnet k = 60`).
- Fallback: If 0 features are selected for a cluster, we dynamically fall back to `min_freq = 0.0` to extract the top features.

### 2. Gating and Specialist Model Training

All regression specialists will be trained on the concatenated `trainval` split using:
```python
XGB_PARAMS = {
    "objective": "reg:squarederror",
    "max_depth": 8,
    "min_child_weight": 10,
    "reg_lambda": 1.5,
    "reg_alpha": 0.03,
    "subsample": 0.9,
    "colsample_bytree": 0.8,
    "n_estimators": 1500,
    "learning_rate": 0.01,
    "random_state": 42,
}
```

For Learned Gating (Models 2-5):
- Gating model is an `XGBClassifier` trained on `trainval` (using `OVERALL_SELECTED_FEATURES_V3` to predict the true regimes).
- Specialists are trained on their respective regime subsets.
- Models 2 & 3 use regime-specific features `*_REGIME_*_SELECTED_FEATURES_V1`.
- Models 4 & 5 use `OVERALL_SELECTED_FEATURES_V3` for all specialists.
- We will measure gating accuracy, precision, recall, and F1-score on the `val` and `test` sets.

For Clustering Gating (Models 6-11):
- Gating at test time is deterministic (e.g. KMeans predict, quantile threshold, or seasonal month).
- Specialists are trained on their respective cluster subsets using cluster-specific features.

### 3. Diagnostic Plots and Outputs

For each model, we will generate:
- **Diagnostic Grid**: A $2 \times 4$ grid containing:
  - Row 1: True vs. Predicted plots for Overall, 2023, 2024, and 2025.
  - Row 2: Residual plots (True vs. Residual) for Overall, 2023, 2024, and 2025.
- **Line Chart**: A single line chart comparing the $R^2$ performance of all 11 models over the test years (2023, 2024, 2025).
- **Model weights**: Saved in JSON format to `models/` directory for fast re-run.
