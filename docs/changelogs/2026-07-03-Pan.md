### Mixture of Experts (MoE)
#### but more extreme
Assume soil-moisture based routing is accurate, `moe-spamming-1.0` shows MoE ~~does have theoretical potentials at R^2=0.98~~, but only is the soil-moisture based routing is accurate.

~~Also, it shows quantile-based threshold doesn't hurt performance as much; in another word, the exact values seems not matter as much when the distribution is balanced.~~ But yeah, in case we continue on true-SM-based routing, we don't need to worry about the exact threshold values, as long as the distribution is balanced. 

Actually, it doesn't work, because each specialists only learns to output values within their narrow range, instead of capturing some underlying features of the data points. So, if we do have a reliable router, then the individual experts don't matter much at all; in another words, making the router to work is equivalent to making a single global model to work. Even then, we need to make sure (i.e. penalize) the model from simply outputting the mean of the target variable's range.

So, the challenge kind of shifted from *handle misrouted data* to *making sure the model actually learn something rather than just output the mean of the target variable's range*. 

Also, might reconsider 2-regime MoE, not because it is easier to route, but to make the model generalize better rather than outputting the training mean of the current bin.
