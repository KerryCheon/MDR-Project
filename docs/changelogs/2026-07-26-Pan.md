# July 26, 2026

## Remove more stations
After removing 3 stations With incomplete data in `derived_8.3`, the model performance doesn't improve as expected.

The real issue is there are stations with Alpine snow pack microclimate that our feature set does not contain enough information to do proper prediction (e.g. snow and rainfall from long time ago, etc.). Therefore, for the time it being I'm going to remove them from our data set entirely. This is also the reason why we need to collect more features in the future.
