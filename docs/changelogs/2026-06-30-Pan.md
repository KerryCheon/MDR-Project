# June 30, 2026

## Continue on dataset: derived_8.1
### Further data exploration
- Created new plot showing aggregated monthly histograms of soil moisture values, revealing seasonal patterns as expected (wet winter, dry summer).

### single global model
- Add residual plots for the single global model, showing that the model is underfitting the data across the entire range of soil moisture values; with roughly half of the data points underpredicting and another half overpredicting. This is expected as the single global model is not able to capture the different regimes in the data.

### 2 regime model
- Trained a 2-regime model (wet, dry) on derived_8.1 dataset, achieving R2 of 0.78 with oracle hard gating. The residuals vs true SM plot shows the same issue as the 3-regime model, the underlying specialists are underfitting the data across the entire range of soil moisture values. So, it's worth to work on improving the specialists, for example by adding temporal drifting similar to v24 and v25.

### 3 regime model
- Trained another 3-regime model (wet, dry, normal) with the same threshold but without regime-specific feature selection, achieving R2 of 0.84 with oracle hard gating. The residuals vs true SM plot shows similar performance as the previous 3-regime model. So the regime separation provided most of the performance gain, and the specialists are still underfitting the data across the entire range of soil moisture values.
