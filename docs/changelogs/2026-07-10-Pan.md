## The single global model
### Feature Selection
The new dataset has doubled the number of stations thus doubled the amount of rows to train on, but the feature selection pipeline still default to 40, let's see if we should increase the number of features to train the model.

Turns out, increasing it to 50 not only increased the performance, but also reduced the previous problem of "dent in 2024" and the unweighted model performed better than the drifted model! 

#### Remove MI stage
- Useless that we literailly have to set k=300 for MI stage when we only have 400 features.
- It removes features that doesn't exhibit strong independent linear/non-linear relationships with the target (soil moisture), but the issue is, there're are many features provide critical joint signal when combined with other features, so it kind of doing the opposite of what we want.
- The heavy lifting is done by ElasticNet stage, that training mini models are more accurate validating the feature importance.
