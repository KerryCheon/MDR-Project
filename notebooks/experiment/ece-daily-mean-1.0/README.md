# Experiment: `ece-daily-mean-1.0`

Audits the ECE 24-hour daily mean against the public-station targets. The executed notebook reported all numbers below; reusable logic lives in `audit_coverage.py`, `compare_averaging.py`, and `snotel_check.py`.

`simple mean` (current pipe) vs `hourly-weighted mean` (USCRN equal-hour weighting) differs by at most 0.0036 (0.36pp). Median/snapshot differ by up to 0.039, so the definition matters most if a snapshot were used. Recommendation: adopt hourly-weighted mean with a minimum-hour rule (e.g. 18/24) to match USCRN Note J.

SNOTEL `.stm` files arrive hourly, not daily-averaged. `snotel_pipe.py` averages redundant sensors per timestamp only. Raw hourly `Value` contains spikes (`max 1327.1`, e.g. `2021-10-15 daily_mean 55.36`), so a daily mean needs QC before use. `derived_8.4/train.csv` is already daily (`9803 rows`, `0 duplicate station-days`), so the hourly-to-daily step that produced it is not in the current pipe and must be recovered before claiming consistency.
