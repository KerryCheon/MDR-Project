# results/

Saved figures and evaluation outputs from model training and analysis.

## figures/

- `temporal/` — time-series predictions, residuals, feature importances, training loss curves
- `loso/` — leave-one-station-out cross-validation scatter plots, R² bars, and residual plots
- `spatial/` — spatial generalization results (Quinault transfer, TemporalSpatial experiments)
- `shap/` — SHAP feature importance plots for each feature set (46 files across 11 feature set variants)
- `writeup/` — figures used directly in the IEEE manuscript (beeswarm, climatology, residuals, SMAP vs optical, weighted vs unweighted model comparison)
